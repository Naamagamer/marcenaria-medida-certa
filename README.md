# Marcenaria Medida Certa

Site institucional estático. Abra `site/index.html` no navegador ou inicie um servidor local de dentro da pasta `site` com `python -m http.server 4173`; depois acesse `http://localhost:4173`.

As capturas continham a logo, nove fotos de projetos, o retrato atualizado de David (“DAVID FOTO 2.0.png”), os logos do Instagram e do WhatsApp e 17 screenshots de feedbacks. A página inclui botões sociais no CTA final, um carrossel de feedbacks com navegação lateral, e rolagem mais curta na abertura.

Na seção Contato, WhatsApp, Instagram e e-mail são links diretos. O CTA final leva ao Instagram, WhatsApp e YouTube.

## GitHub Pages

O workflow em `.github/workflows/deploy.yml` publica o conteúdo de `site/` no GitHub Pages sempre que houver push para a branch `main`. Depois de criar o repositório, habilite Pages com a fonte **GitHub Actions** em Settings → Pages.
